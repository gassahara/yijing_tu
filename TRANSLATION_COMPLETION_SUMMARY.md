
### Remedy Name Resolution (`_resolveRemedyName`)
```javascript
// Checks name object for language-specific translation first
if (typeof remedy.name === 'object') {
    if (remedy.name[lang]) return remedy.name[lang];  // Uses es/it from DB
    // Falls back to REMEDY_NAME_TRANSLATIONS map
}
```

## How It Works

1. **3-Tab Architecture:** The new concurrent tab endpoints generate content directly in the target language
2. **Database Fallback:** Static content (names, judgments, lines) is read from the JSON/JS files
3. **Dynamic Content:** Remedy descriptions and instructions are generated by the AI in the target language
4. **Frontend Resolution:** The `_resolveRemedyName` function checks the name object first, then falls back to the translation map
