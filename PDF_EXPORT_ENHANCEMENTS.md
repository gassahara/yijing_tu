# PDF Export Enhancements

## Overview
Enhanced the PDF export functionality to include complete technical details, diagrams reference, and comprehensive analysis sections.

## Changes Made

### 1. Backend - `supabase_function.ts`

#### Enhanced `generatePDF()` function with:
- **Bagua Medicine & Feng Shui Section**
  - Favorable/unfavorable directions
  - Feng shui guidance
  - Alchemical medicine details

- **Technical Analysis Section**
  - Later Heaven (Houtou) technical analysis
  - Emperor and master analysis

- **Xiantian (Early Heaven) Section**
  - Spiritual essence
  - Inner alchemy guidance
  - Cultivation advice

- **Five Elements Equilibrium**
  - Yin-Yang balance counts
  - Element distribution details

- **Advanced BaZi Analysis**
  - Hetu (River Map) analysis
  - Luoshu (Magic Square) with Life Gua
  - Xiantian trigrams
  - Three Treasures (Jing/Qi/Shen)
  - Congenital nature

- **Diagrams Reference Page**
  - Hexagram visualization
  - Bagua diagram
  - Elements chart
  - Fulu (Talisman) diagrams
  - Xiantian diagram

### 2. Frontend - `app.js`

#### Enhanced `generateExportData()`:
- Added `includeFullDetails` parameter
- Includes extended BaZi analysis (Hetu, Luoshu, Xiantian)
- Adds Xiantian interpretation
- Adds Bagua Medicine data
- Adds FDL diagrams reference

#### Updated `exportReading()`:
- Added 'pdf-full' format option
- Standard 'pdf' exports basic reading
- 'pdf-full' exports complete technical document

#### Updated `exportToPDFServer()`:
- Accepts `includeFullDetails` parameter
- Logs export type for debugging

### 3. UI - `index.html`

#### Added "Full PDF" button:
- Located next to standard PDF button
- Exports complete document with all technical details
- Tooltip: "Export Full Document with All Technical Details"

## Usage

### Standard PDF Export
```javascript
App.exportReading('pdf');
```
Includes: Basic reading, interpretation, remedies

### Full PDF Export
```javascript
App.exportReading('pdf-full');
```
Includes:
- Basic reading data
- Complete interpretation (all sections)
- Celestial influences with BaZi
- Five Elements analysis
- Moving lines analysis
- Classical texts (Judgment, Image, Line texts)
- Daoist remedies (Fulu, Fuzhou)
- **Bagua Medicine & Feng Shui**
- **Technical Analysis (Later Heaven)**
- **Xiantian (Early Heaven) Analysis**
- **Five Elements Equilibrium**
- **Advanced BaZi Analysis (Hetu, Luoshu, Xiantian)**
- **Diagrams Reference Page**

## PDF Structure

```
Page 1: Title & Hexagram Info
  - Hexagram number, name (EN/ZH)
  - Date and binary code
  - Question

Page 1-2: Hexagram Visualization
  - Visual representation of 6 lines
  - Line details (position, type, changing)

Page 2-3: Analysis Sections
  - Lunar Mansion
  - Celestial Influences (with BaZi)
  - Five Elements
  - Core Analysis
  - Advice
  - Moving Lines
  - Classical Texts

Page 3-4: Remedies
  - Daoist remedies (Fulu)
  - Charms/Incantations (Fuzhou)
  - Sources

Page 4-5: Advanced Technical
  - Bagua Medicine & Feng Shui
  - Technical Analysis (Houtou)
  - Xiantian Analysis
  - Five Elements Equilibrium
  - Advanced BaZi (Hetu, Luoshu, Xiantian)

Page 5+: Diagrams Reference
  - Description of all generated diagrams
  - Technical specifications

Footer: Generated by Yijingtu I Ching Oracle
```
